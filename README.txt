妖怪二十二絵図占術　第一期完成版 v1.3.3 カード完全補正版

【起動方法】
1. ZIPファイルを右クリックし、「すべて展開」を選びます。
2. 展開したフォルダを開きます。
3. index.htmlをダブルクリックします。

追加ソフト、簡易サーバー、インターネット接続は必要ありません。

【第一期完成版の内容】
・正式設定集に基づく全22枚のカード情報
・「正位置／逆位置」を廃止し、「陽／陰」へ完全統一
・陽と陰を、良い／悪いではない二つの働きとして説明
・22枚 × 7テーマ × 陽陰＝308通りの鑑定結果
・各絵図の季節、方角、色、自然の力、象徴を表示
・カードシャッフル演出
・効果音ON／OFF
・占い履歴30件
・結果コピー
・スマートフォンとキーボード操作に対応
・index.htmlのダブルクリック起動に対応

【保存される情報】
占い履歴と音の設定は、お使いのブラウザ内だけに保存されます。
インターネットや外部サーバーには送信されません。

【重要】
本占術は娯楽と自己対話を目的とします。
医療、法律、投資などの重要な判断には使用せず、適切な専門家へご相談ください。


【v1.0.1の修正】
第8番「忍耐／河童」のカード画像内の言葉を修正しました。
陽：忍耐・持続・受容
陰：焦り・執着

水の流れに逆らわず力を蓄える河童の世界観と、
カード名「忍耐」が自然につながる表現へ統一しています。


【v1.1.0の重要な変更】
全22枚のカード画像について、下部に印刷されている用語を見直しました。

・「正／逆」ではなく「陽／陰」に統一
・意味が伝わりにくい言葉を、一般的で自然な日本語へ変更
・各札の名前、妖怪、短い言葉、サイト内の鑑定データを一致
・第8番「忍耐／河童」の修正内容も維持

画像とサイト表示が同じキーワードを使用するため、
カードを見たときと結果を読んだときの意味が食い違わない構成です。


【v1.2.0のテーマ選択】
自由記入の「心の中の問い」は削除し、選択式のテーマを12項目へ細分化しました。

全体運／今日の流れ／恋愛・関係／出会い・片思い
仕事・役割／転職・挑戦／人間関係／家族・身近な人
金運・支出／健康・生活／迷い・決断／心の整理

入力せずにテーマを選ぶだけで占いへ進めるため、
操作が簡単になり、鑑定結果もテーマに沿った内容になります。


【v1.2.1 鑑定文完全リライト】
結果画面を次の4部構成へ変更しました。

1. 妖怪からの言葉
2. 選択したテーマに沿った読み
3. 今日の導き
4. この妖怪について

各妖怪の姿、性質、札の役割が一つの文章としてつながるよう、
全22枚の陽・陰の文章を個別に書き直しています。
